## 运行实验

Python 3.10+，只用标准库，不需要真实模型 API key、外网或第三方 Python 依赖：

```sh
python3 -m lab.demo --evidence lab/evidence/demo.json
python3 -m unittest discover -s tests -v
```

交互方式：

```sh
python3 -m lab.demo --serve --port 8088
```

请求示例、配置与具体测试见 [lab/README.md](lab/README.md)。上游替身、网关与客户端使用真正的环回 HTTP 连接；演示包括显式授权的受控切换、流中断不重放、未知用量、租户取消、并发准入与慢消费者。

## 实验保证与边界

- 默认不重放 POST。只有请求明确授权、路由配置可信、替身返回私有“未开始”承诺时，才允许受限的应用层后续尝试；普通 503、连接异常、无输出与流中断不提供同样保证。
- 计量合同为 `utf8-bytes-v1`，一 credit 是一个 UTF-8 文本字节，不能当作真实模型 token 或货币费用。可信完整 usage 加 done 并完成本地写入才结算；中断保留 unknown 预留。
- 实验可观察本地连接关闭和替身停止发送；不能证明真实供应商停止计费，也不能回滚已经发生的业务工具动作。
- 单进程内存账本、内存审计、环回 HTTP，没有 TLS、持久恢复、多实例一致性、真实模型接口兼容或供应商账单对账。生产设计章说明需要新增哪些保证。

案例均为教学场景；没有声称真实供应商质量排名、吞吐基准或生产事故经历。

## 构建与阅读站

需要 Pandoc 3.12.1、Python 3.10+；EPUBCheck 需要 Java 17+：

```sh
python3 scripts/build.py
python3 scripts/verify.py
sh scripts/epubcheck.sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory site
```

访问 `http://127.0.0.1:8767/`。阅读页默认浅色，支持手动深色、同域共享主题偏好、搜索、字号、移动目录、前后章和阅读位置；禁用 JavaScript 仍可阅读正文与翻页。构建同时输出 EPUB、离线 HTML、完整 Markdown 与实验 ZIP。

构建器验证源稿、网页、EPUB 的逐章正文一致性；浏览器检查负责真实页面交互；EPUBCheck 负责 EPUB 格式。内容准确性与实验语义仍需独立审阅，不能由一个绿色检查替代。

完整约定、浏览器测试和发布命令见 [scripts/README.md](scripts/README.md)。推送 main 后，GitHub Actions 运行实验、构建、验证和浏览器检查，再发布 GitHub Pages。
